# Flobordo — downloads

Sticky notes and flows on a whiteboard that stays offline.

No internet, no accounts, no cloud. Flobordo only reads and saves the folder you pick — a local one, or one inside OneDrive, Google Drive or iCloud Drive, so a team can work on the same boards.

**[Download the latest version](https://github.com/Jjahonen/flobordo-releases/releases/latest)**

This repository holds only the installers. Each release lists what's new.

## Installing

Flobordo is for macOS (Apple Silicon and Intel). Open `Flobordo_x.y.z_universal.dmg` and drag Flobordo to Applications. The app is signed and notarized by Apple, so it opens without warnings.

Everyone who shares a board folder should use the same version.
