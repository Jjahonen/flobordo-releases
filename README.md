# Flobordo — downloads

Sticky notes and flows on a whiteboard that stays offline.

No internet, no accounts, no cloud. Flobordo only reads and saves the folder you pick — a local one, or one inside OneDrive, Google Drive or iCloud Drive, so a team can work on the same boards.

**[Download the latest version](https://github.com/Jjahonen/flobordo-releases/releases/latest)**

This repository holds only the installers. Each release lists what's new.

## Installing

- **macOS** (Apple Silicon and Intel): download `Flobordo_x.y.z_universal.dmg`, open it and drag Flobordo to Applications. The app is signed and notarized by Apple, so it opens without warnings.
- **Windows 10/11:** download `Flobordo_x.y.z_x64-setup.exe` (Intel/AMD laptops) or `Flobordo_x.y.z_arm64-setup.exe` (Snapdragon/ARM laptops such as Surface) and run it. The Windows installer isn't signed yet, so Windows shows "Windows protected your PC" the first time: click **More info ▸ Run anyway**. (The `.msi` is the x64 app for IT-managed installs.)

Everyone who shares a board folder should use the same version.
